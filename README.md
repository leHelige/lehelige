## About

I'm a cybersecurity professional based in Brazil, working across security investigations, detection engineering, and defensive infrastructure. My primary interest is **hands-on Digital Forensics & Incident Response (DFIR)**: reconstructing attacker activity, examining evidence, scoping incidents, and supporting effective containment and recovery.

I also design and operate detection and telemetry pipelines, which gives me a practical perspective on both **collecting evidence** and **using it during an investigation**.

## DFIR focus

- **Endpoint forensics:** Windows artifacts, process execution, persistence, timelines, and filesystem evidence.
- **Memory forensics:** process and memory analysis to investigate suspicious activity.
- **Network forensics:** packet analysis, traffic reconstruction, and intrusion scoping.
- **Incident response:** triage, evidence collection, attacker TTP reconstruction, containment, and lessons learned.
- **Threat hunting:** hypothesis-driven analysis using endpoint and log telemetry, informed by MITRE ATT&CK.

## Building: InvestigateCLI

**InvestigateCLI** is my in-progress Rust CLI for practical IOC enrichment and investigation support.

It prioritizes bounded and resilient API interactions, provenance-aware results, predictable error handling, and secure-by-default behavior. The goal is to help analysts move from an indicator to useful context without hiding uncertainty or replacing investigative judgment.
